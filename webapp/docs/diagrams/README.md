# Gemini Translate 前后端分离版本图表

本目录包含前后端分离版本的Gemini Translate应用程序的各种图表，用于说明系统架构、流程和交互。

## 可用图表

### 用户流程时序图

1. [用户流程时序图 (Mermaid版)](user_flow_sequence_diagram.md)
   * 展示用户从打开应用到下载翻译结果的完整交互流程
   * 使用Mermaid标记语法创建，便于在GitHub等平台直接查看

2. [用户流程时序图 (HTML版)](user_flow_sequence_diagram.html)
   * 同一用户流程的交互式HTML版本
   * 提供彩色编码和更详细的视觉表现

## 如何查看

- **Mermaid图表**: 可以在支持Mermaid语法的任何Markdown查看器中直接查看
- **HTML图表**: 使用任何网络浏览器打开查看交互式图表

## 与Gradio版本的区别

前后端分离版本的时序图相比Gradio版本有以下主要区别：

1. **组件分离**: 清晰区分前端、后端API、任务队列和AI模型API
2. **API调用**: 展示了明确的RESTful API调用路径
3. **异步处理**: 包含任务队列作为独立组件来处理异步翻译任务
4. **状态轮询**: 展示前端如何通过轮询获取任务进度
5. **数据流**: 更详细地展示了数据如何在各组件间流动
