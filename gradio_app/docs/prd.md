# Gemini Translate - 产品需求文档 (PRD)

## 1. 产品概述

Gemini Translate 是一个基于 AI 模型的批量翻译工具，专门用于商品数据的翻译和原创化处理。该工具使用 Google Gemini 和 OpenAI 模型，能够将批量的商品数据（如标题、描述、选项等）从一种语言翻译成另一种语言，同时保持数据的结构和格式，为电子商务联盟营销（Affiliate Marketing）业务提供技术支持。

### 1.1 产品背景

在电子商务和跨境贸易领域，商品数据的多语言翻译是一个常见需求。我们的业务模式是通过大量采集电商平台（如亚马逊）的产品数据，利用 AI 翻译和内容原创化处理后，将这些产品信息发布到自建网站上。当用户通过我们的网站购买产品时，原电商平台商家负责发货和客户服务，而我们获取25%-30%的销售佣金。

传统的翻译方式往往效率低下、成本高昂，且难以保持专业术语的一致性。Gemini Translate 通过利用先进的 AI 模型，提供高效、准确的商品数据翻译和原创化服务，是实现我们联盟营销业务模式的关键技术工具。

### 1.2 目标用户

- 电子商务联盟营销（Affiliate Marketing）从业者
- 跨境贸易从业者
- 需要批量翻译和原创化商品数据的企业或个人
- 内容营销团队

## 2. 功能需求

### 2.1 核心功能

#### 2.1.1 文件上传

- 支持上传 CSV 格式的商品数据文件
- 提供用户友好的上传界面
- 显示上传进度和状态

#### 2.1.2 翻译配置

- 支持选择目标翻译语言
- 支持选择不同的 AI 模型（如 Gemini-1.5-flash, GPT-4o 等）
- 支持配置翻译 API 参数

#### 2.1.3 批量翻译

- 自动解析上传的 CSV 文件
- 识别需要翻译的字段（如 Title, Body (HTML), Option Name, Option Value 等）
- 执行并行翻译请求以提高效率
- 支持 JSON 和 HTML 两种主要内容类型的翻译

#### 2.1.4 结果导出

- 提供翻译结果的下载功能
- 保持原始文件的结构和格式
- 支持导出为 CSV 格式

#### 2.1.5 内容原创化

- 支持对翻译结果进行原创化处理
- 在保持产品核心信息准确的前提下提高内容独特性
- 提供内容原创度调节参数

### 2.2 辅助功能

#### 2.2.1 缓存管理

- 支持翻译结果缓存，减少重复翻译
- 支持缓存的加载和保存

#### 2.2.2 API 配置管理

- 支持管理多个 API 密钥和配置
- 支持上传和加载 API 配置文件

#### 2.2.3 进度显示

- 实时显示翻译进度
- 提供翻译状态和完成情况的可视化展示

## 3. 技术规格

### 3.1 系统架构

- 基于 Python 的 Web 应用
- 使用 Gradio 构建用户界面
- 使用并发处理技术提高翻译效率

### 3.2 API 集成

- 支持 Google Generative Language API (Gemini 系列模型)
- 支持 OpenAI API (GPT 系列模型)
- 支持自定义 API 配置和多个 API 密钥

### 3.3 翻译处理

- 针对 JSON 数据的专门翻译处理流程
- 针对 HTML 内容的专门翻译处理流程
- 并发执行翻译请求，提高批量处理效率

### 3.4 代理设置

- 提供网络代理配置，解决中国大陆无法直接访问 Gemini API 的问题
- 内置 V2Ray 代理配置和自动启动功能

## 4. 用户界面

### 4.1 主界面

- 文件上传区域
- 模型选择下拉菜单
- 目标语言选择器
- API 配置管理区域
- 并发数量设置
- 开始翻译按钮
- 翻译进度显示
- 结果下载按钮

### 4.2 设置界面

- API 配置上传和管理
- 缓存设置
- 代理配置

## 5. 使用流程

1. 启动应用（可能需要配置代理）
2. 上传 CSV 格式的商品数据文件
3. 选择目标翻译语言
4. 选择翻译模型
5. 配置 API 参数（如有必要）
6. 点击"开始"按钮开始翻译
7. 等待翻译完成
8. 下载翻译结果

## 6. 技术要求

### 6.1 开发环境

- Python 3.6+
- 依赖包：
  - gradio
  - pandas
  - openai
  - 其他相关依赖

### 6.2 运行环境

- 支持 Linux 操作系统
- 需要网络连接
- 可能需要配置网络代理（中国大陆用户）

### 6.3 API 需求

- Google Generative Language API 密钥
- OpenAI API 密钥
- 网络代理配置（中国大陆用户）

## 7. 限制和约束

- 需要适当的 API 密钥和配置
- 翻译质量依赖于所选 AI 模型的能力
- 在中国大陆使用可能需要配置网络代理
- 大量数据翻译可能导致 API 费用增加

## 9. 结语

Gemini Translate 旨在为联盟营销业务提供高效、准确的商品数据翻译和原创化服务。通过集成先进的 AI 模型和批量处理技术，该工具能够满足跨境电商和多语言数据处理的需求，显著提高商品数据翻译的效率和质量，支持"零库存"电商联盟营销业务模式的实现。
